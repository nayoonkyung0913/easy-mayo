# MINES Easy Mayo

기획 미리보기 0.2.0. 사용자가 카작과 동일한 레이아웃·스크롤 이벤트·인터랙션을 명시했다. 이후 작업은 이 기준을 유지한다. 0.1의 독자적인 레이아웃 및 순서 변경은 폐기했다.

카작 3.0.2, 커밋 `4825215`의 최신 본문, CSS, JavaScript를 직접 이식했다. 메인 모임, 갤러리 루프·이전·다음·정지, 모바일 스냅, 질감 장면 이동, 고정 제목과 가로 카드 이동, 레시피 왕복 회전, 2초 간격 맛 전환, 키보드 탭 선택, 모션 감소 대응을 같은 코드로 처리한다. namespace와 총내용량(280g) 외에는 JavaScript 로직을 변경하지 않는다.

- `index.html`: 반응형 상세페이지 시안
- `plan.html`: 기존 상세 분석, 카작 대응 레이아웃, 이미지 사용 계획
- `sauce-reference.json`: 실촬영 기준 색상, 샘플 위치, 원본 SHA-256
- `assets.json`: 검증된 카페24 주소와 웹 이미지 SHA-256
- `releases/0.2.0/`: 현재 본문, 카작에서 이식한 CSS·JavaScript 및 독립 폰트
- `layout-source.json`: 원본 커밋·파일 해시·허용된 차이
- 루트 `easy-mayo.css`, `easy-mayo.js`: 0.1 이전 시안 자료. 현재 상세페이지는 이 파일들을 사용하지 않는다.

카페24 `/web/upload/easy-mayo/`에서 이미지를 제공한다. 파일 이름에 콘텐츠 해시를 붙여 기존 파일과 충돌하지 않는다. 사진의 색을 변경하지 않았으며 큰 사진은 웹 전송용으로 축소·압축했다. 원본은 작업 폴더 `easy-mayo-staging/references/`에 보존한다.

실제 소스의 색과 결은 사용자가 제공한 260309 실촬영 04(트러플표고), 05-2(흑마늘페퍼)를 최우선으로 삼는다. 기존 AI 이미지의 소스 색을 기준으로 사용하지 않는다. 사진의 HEX는 측색 표준이 아닌 촬영 조건을 포함한 참고값이다. 소스의 작은 입자와 음식에 별도로 올린 토핑은 구분한다.

이 저장소는 카작과 독립되어 있다. 0.2는 독립 폰트를 포함하며 `data-easy-mayo-version`과 `em-` 접두어로 CSS·JS를 분리한다. 원본 섹션 순서를 유지하며 상품에 맞춰 비교 카드와 맛 탭 수만 2개로 맞췄다. 가로 스크롤 장면은 원본의 5카드를 유지하고 두 맛과 음식 조합으로 내용을 채웠다. 제조공정에 관한 근거 없는 설명은 넣지 않고 같은 3단계 배치에 사용 장면을 넣었다.

음식 연출 이미지는 기존 제공 자료의 구도를 확인하는 임시 배치다. 최종 이미지 제작은 저장된 실촬영 소스 색·결을 기준으로 한다. 상품 사진의 흰 배경은 현재 CSS clip-path로 임시 정리하며, 최종 투명 제품 자산으로 교체할 예정이다.

최종 전환 시 최신 제품 라벨로 원재료·영양정보·알레르기·보관방법을 대조한다. 현재 상품 에디터에는 적용하지 않았다.
