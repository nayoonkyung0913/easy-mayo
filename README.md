# MINES Easy Mayo

현재 미리보기 0.3.0. 카작 3.0.2(4825215)를 기반으로 한 독립 이지마요 상세페이지다. 실제 아임웹 상품에는 아직 적용하지 않았다. 사용자에게 HTML 코드 대신 미리보기를 제공한다.

## 사용자 지시의 변경 이력

- 0.2: 카작의 동일한 섹션 레이아웃, 스크롤 이벤트, 인터랙션을 이식.
- 0.3: 이지마요의 크림·베이지·브라운 팔레트 적용. 중복된 ‘두 가지 풍미, 다채로운 한 끼’를 제거하고, 그 pinned horizontal rail을 ‘쭉 짜는 순간부터 맛있는 한 입까지’의 3단계 사용법에 적용.
- 질감 소개 구간은 왼쪽 위의 큰 제품과 스크롤에 따라 이어지는 소스로 교체. ‘숟가락 없이, 쭉 짜면 완성’을 강조. 기존 hero, gallery, recipe, flavor tab 동작 유지.
- 사용자 제공 서울패키지/4x/아트보드 11.jpg 후면 표시사항을 제품별 상품정보로 작성.

## 현재 파일

- index.html / releases/0.3.0/: 현재 미리보기 본문·CSS·JavaScript·폰트
- product-information.json: 사용자 패키지에서 전사한 제품정보. 590kcal/575kcal는 **100g당** 열량. 총내용량당 성분값을 임의 재계산하지 않는다.
- sauce-reference.json: 실제 소스 기준 색, 샘플 위치, 원본 해시
- assets.json: 카페24 자산 URL·해시
- image-generation.json: 이미지 제작 프롬프트·도구·프로젝트 파일 위치
- layout-source.json: 카작 소스와 후속 변경 범위
- plan.html: 현재 기획 기준

## 이미지 기준

실제 소스는 260309 실촬영 04(트러플), 05-2(페퍼)를 기준으로 한다. 색상 수치는 촬영 광원·화이트밸런스를 포함한 참고값이다. 기존 AI 음식 연출 컷은 구도 참고이며 최종 소스 색과 질감 대조 작업이 남아 있다.

0.3의 제품 누끼와 균일한 소스 질감은 built-in imagegen으로 실촬영 사진을 참고해 제작한 연출 자산이다. 상품정보는 이 이미지의 글자가 아닌 원본 패키지에서 전사했다. 제품 누끼는 독립 SVG image, 소스는 질감 패턴을 입힌 SVG path와 stroke mask로 구성해 스크롤에 따라 나타나고 되감긴다. 모션 정지·prefers-reduced-motion에서는 완성된 소스를 표시한다.

카페24 /web/upload/easy-mayo/의 해시 파일명을 사용한다. 프로젝트 소스는 카작 저장소와 분리한다. 이전 releases 및 루트 0.1 CSS/JS는 기록용이며 현재 상세페이지에서 사용하지 않는다.

## 검증 상태

정적 구조, 상품정보 표, JavaScript 문법, 소스 진행 함수, 카페24 공개 파일 해시를 검사했다. PC 화면에서 팔레트와 짜기 장면을 확인했지만, CUA가 Windows 브라우저 URL을 판독하지 못해 이후 실제 스크롤 및 모바일 육안 검증을 완료하지 못했다. 이를 완료한 것으로 보고하지 않는다.
