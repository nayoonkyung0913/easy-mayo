# MINES Easy Mayo

현재 미리보기는 0.5.4이다. 카작 3.0.2(4825215)를 기반으로 한 독립 상세페이지이며, 실제 아임웹 상품에는 아직 적용하지 않았다. 사용자에게 HTML 대신 미리보기를 제공한다.

## 0.5.4 변경 내용

- 흑마늘페퍼 스테이크 사진의 소스를 실제 촬영 참고 사진에 맞춰 갈색 베이지 색감과 부드러운 질감으로 부분 보정했다. 제품과 라벨은 원본 촬영 픽셀로 보존했다.
- 토스트 사진의 제품 뚜껑은 사용자가 지정한 감자튀김 사진의 형태를 기준으로 보정하고, 입구부터 음식까지 소스가 이어지도록 정리했다. 인쇄된 제품 부분에는 원본 촬영 픽셀을 다시 합성했다.
- ‘숟가락 없이, 쭉 짜면 완성’의 제품은 3126×4689 원본 사진에서 곡선 경계로 다시 추출했다. 제품과 소스 레이어를 분리해 스크롤 중 뚜껑이 잘리는 문제를 수정했다.
- PC 갤러리의 움직임 멈추기·좌우 버튼을 숨겼다. 갤러리와 기존 스크롤 동작은 유지했다.
- 모바일 맛 선택 영역의 원물 조합을 제품 오른쪽 아래에 작게 겹쳐 배치했다. 두 맛 모두 동일한 규칙을 사용하며, 390px 화면에서 원물 영역은 120×80px이다.
- 소스의 시작·중간·끝·역방향 동작과 모바일 가로 넘침을 확인했다. JavaScript는 버전 문자열 외에 0.5.3과 동일하다.

## 0.5.3 변경 내용

- 트러플표고마요 감자튀김·토스트 사진에서 입구에 남아 있던 짧은 소스 조각이 아래 소스와 겹치는 문제를 수정했다. 기존 SVG의 해당 합성 영역만 가려, 이미 보정된 소스 줄기가 입구부터 음식까지 이어지게 했다.
- 제품·라벨·음식의 래스터 원본은 변경하지 않았다. 흑마늘페퍼 사진, 사용법 3장, 카작 갤러리 크기와 모든 스크롤 동작을 유지했다.
- 두 사진의 입구를 확대 비교했다. CSS·JavaScript와 나머지 본문은 버전 문자열 외에 0.5.2와 동일하다.

## 0.5.2 변경 내용

- OPEN. SQUEEZE. ENJOY.를 사용자가 지정한 기존 사용법 클로즈업 PNG 3장으로 교체했다. 열린 뚜껑 → 빵 위로 소스 짜기 → 소스를 올린 토스트 순서이며, 새로 생성하지 않았다.
- MINES EASY MAYO 갤러리는 카작과 동일한 4:3 비율, PC 너비 `max(220px,35vw)`, 모바일 너비 `72cqw`를 사용한다. 사진 내용은 0.5.1의 소스 접점 보정본을 유지했다.
- PC에서 사용법 3장 전체, 모바일에서 마지막 카드까지 표시되는 것을 확인했다. 카작 갤러리 크기는 PC 896×672, 모바일 270×202.5로 확인했다. JavaScript는 버전 문자열 외에 0.5.1과 동일하다.
- 새로 선택한 뚜껑·짜기 PNG를 카페24에 업로드하고 공개 응답 SHA-256을 검증했다.

## 0.5.1 변경 내용

- ‘익숙한 한 끼에, 새로운 풍미 한 줄’의 세 컨셉 사진에서 제품의 위치와 각도를 조정해 노즐이 음식 위를 향하도록 수정했다.
- 소스 줄기와 음식의 접점을 부분 보정했다. 감자튀김·스테이크·버섯 토스트에 연속적으로 닿아 쌓이며, 배경이나 떠 있는 재료로 향하지 않는다.
- 보정 후 제품·손·뚜껑·라벨은 원본 실제 촬영 픽셀로 다시 합성했다. 제품 그림이나 글씨를 생성 결과로 대체하지 않는다.
- 세 장을 확대 검수하고 PC·모바일에서 표시를 확인했다. 새 카페24 파일 3개의 공개 응답 SHA-256을 검증했다. CSS와 JavaScript는 버전 문자열 외에 0.5.0과 동일하다.

## 0.5 변경 내용

- 가로 컨셉 3장의 음식·배경을 새로 제작했다. 제품·손·뚜껑은 사용자 실제 촬영 사진을 SVG에 그대로 넣고 외곽을 잘라 합성했다. 생성 과정에서 바뀐 제품은 사용하지 않는다. 소스 줄기도 실제 사진을 길이 조정해 사용했다.
- 네 번째 섹션의 잘못된 로고·문구 이미지를 실제 트러플 제품 사진으로 교체했다. 수직 소스 스크롤과 상단 제품 크롭을 유지했다.
- 사용법은 실제 열린 뚜껑, 실제 입구와 소스, 완성된 토스트 연출 사진으로 구성했다. 과도한 확대를 줄이고 4:3 구도를 적용했다.
- 하단 트러플 배경은 짙은 웜그레이, 흑마늘 배경은 밝은 회색이다. 선택한 맛에 따라 글자색도 함께 바뀐다.
- 메인·하단 정면 컷과 음식 회전·메인 모이기·사용법 가로 이동 계산은 0.4와 동일하다.
- 변경된 화면을 PC와 모바일 390×844에서 확인했다. 공개 카페24 파일 48개의 해시를 검증했고, 0.5 동작 검사에서 소스 진행률·카작 음식 모션 일치·사용법 마지막 카드 경계가 통과했다.

## 0.4 변경 내용

- 메인과 하단을 같은 정면 스튜디오 누끼컷으로 통일했다. 두 맛의 플라스틱 용기는 같은 굴곡을 가지며, 앞면 종이 패키지는 직사각형이다.
- 제품 컨셉 이미지 3장과 원물 조합 2종, 소스가 올라간 음식 누끼 8종을 반영했다.
- 용량 강조 구간을 빵·감자 / 고기·튀김 활용법으로 바꾸고 제품을 함께 배치했다.
- ‘숟가락 없이, 쭉 짜면 완성’은 큰 한국어 문구 왼쪽, 상단이 잘린 제품 오른쪽으로 구성했다. 소스는 스크롤에 따라 수직으로 드러나며 역방향 스크롤 시 되감긴다. 하단 안내 문구는 삭제했다.
- 사용법 3단계는 실제 촬영 사진을 확대해 보여준다. PC에서는 끝 지점에 세 카드가 모두 들어오고, 모바일에서는 마지막 카드까지 이동한다.
- 음식 사진은 카작과 동일한 스크롤 회전 계산을 사용한다. 설명은 고정되며, 각 설명에 추천 제품 누끼와 이름을 추가했다.
- 하단 맛 선택은 제품 하나와 원물 조합을 보여준다.

## 파일과 이미지 기준

- `index.html`, `releases/0.5.4/`: 현재 본문, CSS, JavaScript, 폰트
- `product-information.json`: 사용자 패키지에서 전사한 표시사항. 영양정보를 이미지 생성 결과로 덮어쓰거나 임의 재계산하지 않는다.
- `sauce-reference.json`: 실제 소스 색 참고값과 원본 정보. 촬영 조명과 화이트밸런스를 포함하며 표준 측색값이 아니다.
- `assets.json`: 카페24 이미지 URL 및 SHA-256
- `image-generation-v4.json`, `image-generation-studio-v4.json`: built-in image_gen 제작 프롬프트와 최종 자산 기록
- `image-generation-v5.json`: 음식 연출 제작 프롬프트와 실제 제품 사진 합성 방식
- `image-generation-v6.json`: 소스 연결부의 부분 보정 프롬프트와 실사 제품 보존 방식
- `image-selection-v7.json`: 기존 사용법 클로즈업 선택 및 카작 갤러리 크기 기준
- `image-adjustment-v8.json`: 트러플 입구의 소스 겹침을 제거한 SVG 합성 범위
- `image-generation-v9.json`: 실제 소스 색감·토스트 뚜껑 보정 프롬프트, 선택한 결과와 원본 제품 보존 방식
- `layout-source.json`, `plan.html`: 적용 기준

메인·하단 제품 누끼와 음식 누끼는 사용자 실촬영을 참고해 제작·보정한 0.4 연출 자산이다. 컨셉 사진의 인쇄된 제품 부분과 네 번째 섹션은 원본 실촬영 픽셀을 사용한다. 0.5.4 토스트 뚜껑과 소스 연결부는 감자튀김 사진을 참고해 부분 보정했다. 현재 사용법 3장은 이전에 생성한 연출 사진이며, 사용자의 지정에 따라 선택했다. 원본 사진과 생성·보정 자산을 혼동하지 않는다. 상품정보의 기준은 사용자 제공 패키지 표시사항이다.

이미지는 카페24 `/web/upload/easy-mayo/`의 해시 파일명을 사용한다. 최종 이미지 원본은 인접 작업 폴더 `easy-mayo-staging/web/`에 보관한다. 과거 릴리스와 루트 0.1 CSS/JS는 기록용이다.

## 검증

- JavaScript 문법, 카작 음식 모션 계산 일치, 소스 시작·중간·끝·역방향·모션 정지 처리를 확인했다.
- 가로 사용법의 마지막 카드 경계를 PC와 모바일 크기에서 검사했다.
- Chrome PC 2560×1215 및 모바일 390×844에서 메인, 활용법, 소스, 사용법, 음식별 제품 표시, 하단 제품을 육안 확인했다. PC 사용법 카드 3장이 모두 보이며 모바일 마지막 카드도 끝까지 나타난다.
- 이미지 41개를 카페24에 업로드하고 공개 응답의 파일 해시를 확인했다.
- 실제 아임웹 편집기 및 사이트 내부에서의 최종 검증은 아직 하지 않았다.
